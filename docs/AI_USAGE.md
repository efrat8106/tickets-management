# AI Usage Log

Running log of where AI assistants were used during development, and what was reviewed or changed by hand.
This log feeds the "AI usage" section of the README.

Tools: **Claude Code** (agent in VS Code, writes code and docs) and **Claude (chat)** (used by the author as a second
reviewer of plans and outputs).

| 10 | T-11 List endpoint | Claude Code wrote `TicketQueryService` (dynamic IQueryable filters, prefix search, whitelisted sorting with `Id` tie-breaker, projection, separate count), DTOs, controller, UTC conversion for dates. | Verified against 100k rows via HTTP and the EF SQL log: WHERE/IN/LIKE…ESCAPE/ORDER BY…Id/OFFSET-FETCH all in SQL, only DTO columns selected, no query for pages beyond the end, wildcard characters in search escaped, Hebrew prefix search works, dates returned with `Z`.
